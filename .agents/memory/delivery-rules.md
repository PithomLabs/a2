# Delivery location rule (set 2026-11-10)

All Markdown deliverables go under `plans2/` in the a2 repo — even when a
prompt names another path (`docs/stack/`, `poc/`, `plans/`). Do not create
doc files outside `plans2/`; mirror the specified filenames inside `plans2/`.
Applies prospectively (existing files stay where they are unless asked to move).
