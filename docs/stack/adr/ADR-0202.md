# ADR-0202 — Fate of migration 00013

Status: PROPOSED (research gate; self-approved — no reviewer available, see §7).
Date: 2026-11-10.

## Context

Migrations 00001–00012 are frozen under all options (binding Key Decision #7).
Phase 0 establishes that schema reflects settled semantics and 00013 comes
only after the eight business decisions (DOCUMENTED
[decisions.md](/home/chaschel/Documents/go/a2/plans2/checklist/decisions.md:690-714)).
The POC needs: cutoff/close state, back-link columns (`ledger_tx`,
`ledger_alh`, `ledger_verified_at`), outbox table, temporal range columns /
keys, DBOS `dbos` schema objects, and any Gate-2 barrier changes — but the POC
lives in `poc/payroll-month/` on branch `stack-poc`, uncommitted until gate
review, on disposable DBs (binding Key Decision #3).

## Decision

00013 does NOT exist yet. No numbered migration is authored during research or
for the POC. POC schema needs are met by POC-scoped SQL under
`poc/payroll-month/` (separate goose chain or setup scripts on disposable
DBs — POC build chooses, ASSUMPTION). A real 00013 is authored only after:
(1) human sign-off of D1–D8, (2) research-gate approval, (3) POC validation of
the schema shape. Its content will be the settled-semantics subset proven by
the POC (close lifecycle, back-links, outbox, temporal keys), never a blend of
POC scaffolding and production DDL.

## Alternatives considered

1. Author 00013 now from proposed semantics — REJECTED: pre-empts HUMAN
   decisions D1–D8 and the pending Gate 1 decision (DOCUMENTED blockers).
2. POC writes directly against 00001–00012 with no new DDL — REJECTED:
   back-links, outbox, and close state have nowhere to live (INFERRED).
3. POC-scoped DDL later promoted verbatim to 00013 — REJECTED: POC scaffolding
   (test hooks, relaxed guards) must not leak into the production chain
   (ASSUMPTION: synthesis rule).

## Consequences

- Production schema stays exactly 00001–00012 through the POC.
- POC DDL is disposable by construction; anything worth keeping is re-derived
  as 00013 from settled decisions + POC evidence.
- 00012's forward-guarded Down (refuse-if-rows) pattern should be mirrored by
  any destructive POC teardown guard (INFERRED suggestion).

## Revisit trigger

Research-gate approval + D1–D8 sign-off → authorize 00013 scoping from POC
results. If POC proves the schema shape wrong, 00013 scope re-derives; no
sunk-cost promotion.
